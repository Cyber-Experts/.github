# Cyber-Experts

Cyber-Experts builds cyber security and digital forensics tools, log and artifact parsers, and educational guides and references on security topics.

Several tools run entirely in the browser: files are parsed on the visitor's device and are not uploaded.

## Public repositories

- [evtx-parser](https://github.com/Cyber-Experts/evtx-parser): Browser-side Windows Event Log (.evtx) parser. Rust core compiled to WebAssembly, no upload.
- [mac-dump](https://github.com/Cyber-Experts/mac-dump): macOS memory-forensics toolkit: logical (per-process) acquisition on Apple Silicon and Intel, physical RAM on Intel via kext, and VM-guest acquisition (Volatility-compatible).
